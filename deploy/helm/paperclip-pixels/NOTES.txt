Security:
  - NetworkPolicies default-deny ingress; the plugin feed (port {{ include "paperclip-pixels.feedPort" . }})
    is reachable only from the Paperclip host pod.
  - TLS/mTLS is the default for the public ingress and for the in-cluster feed
    channel (https). Cleartext HTTP for internal hosts remains available via
    transport.feed.scheme=http + transport.feed.allowedHttpHosts.
